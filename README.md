# SAT Vocabulary Battle 🥊

An interactive SAT vocabulary practice game designed to make learning advanced vocabulary more engaging and challenging. 📚

## About the Project 😉✨

This project is based on SAT vocabulary and other vocabulary resources.

The goal is to help other students learn and practice advanced English words through an interactive sentence-completion game.

Instead of simply asking for definitions, the game gives you sentences with missing words and challenges you to choose the correct word from the provided vocabulary list.

## 🌟 Features
- 📖 25 advanced SAT vocabulary words
- 🧠 Vocabulary section with meanings and examples
- 🥊 25 sentence-completion battles
- 🎲 Random question order
- ⌨️ User input
- ✅ Instant feedback for correct answers
- ❌ Correct answer shown after a mistake
- 🏆 Final score out of 25
- 📊 Performance-based feedback
- 🔄 Play Again option
- 🚫 No multiple-choice options
- 💪 Words can only be used once

## 🎮 How to Play

1. Review all 25 vocabulary words.
2. Confirm that you are ready.
3. Read each sentence carefully.
4. Fill in the missing word using the vocabulary list.
5. Complete all 25 battles.
6. Check your final score.
7. Play again if you want to improve your score! 🔥
